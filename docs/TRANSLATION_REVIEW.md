## 🔍 Native Verification Notes
- **Santali (Ol Chiki)**: Uses standard Unicode Ol Chiki (`\u1C50`–`\u1C7F`) rendered crisply across mobile devices and modern desktop browsers.
- **Urdu & Arabic**: Rendered right-to-left with automatic `dir="rtl"` applied at the root container level.
- **Jharkhand Dialects (Nagpuri, Khortha, Kurukh, Mundari, Ho)**: Formally supported with Devanagari / native scripts in the Language Selector with prominent "Beta" tags.
